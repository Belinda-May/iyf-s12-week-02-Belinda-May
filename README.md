# My Personal Portfolio – Week 2

## About the Project
This is my personal portfolio website, developed as part of the IYF Season 12 programming course.

The project builds on my Week 1 HTML portfolio by introducing CSS styling, Flexbox, CSS Grid and responsive web design.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Git and GitHub

## Website Pages
- **Home:** Introduction to me.
- **About:** My background, interests and hobbies.
- **Projects:** A showcase of my projects and learning activities.
- **Contact:** How to get in touch with me.

## Features
- Responsive layouts for mobile, tablet and desktop.
- Flexbox navigation.
- CSS Grid project layout.
- Consistent colours and typography.
- Hover and keyboard focus effects.
- Semantic HTML structure.
